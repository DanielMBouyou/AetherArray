# Glossaire

- Statut : vivant, à compléter au fil des lectures

## Réseaux d'antennes

| Terme | Définition courte |
| --- | --- |
| Réseau à commande de phase | ensemble d'antennes dont on règle les phases pour orienter le faisceau |
| Facteur de réseau | fonction décrivant le champ résultant de la combinaison des éléments |
| Diagramme de rayonnement | représentation de la puissance émise en fonction de la direction |
| Lobe principal | direction où le réseau émet le plus |
| Lobe secondaire | direction parasite où le réseau émet encore de l'énergie |
| Faisceau parasite de réseau | second lobe aussi fort que le principal, dû à un espacement trop grand |
| Largeur de faisceau | ouverture angulaire du lobe principal, mesurée à mi-puissance |
| Dépointage | fait d'orienter le faisceau hors de l'axe |
| Déviation en fréquence | fait que la direction de pointage change avec la fréquence |
| Couplage mutuel | influence des éléments voisins les uns sur les autres |
| Diagramme d'élément incorporé | diagramme d'un élément mesuré en présence des autres |
| Impédance active | impédance vue par un élément quand les autres sont alimentés |
| Formation de faisceau analogique | orientation obtenue par déphasage du signal RF |
| Formation de faisceau numérique | orientation obtenue par calcul sur des voies échantillonnées |
| Champ lointain | zone où l'onde peut être considérée comme plane |
| Champ proche | zone proche du réseau, où la mesure demande un traitement particulier |

## Composants

| Terme | Définition courte |
| --- | --- |
| Déphaseur | composant qui retarde la phase d'un signal, de façon réglable |
| Atténuateur | composant qui réduit l'amplitude, de façon réglable ou fixe |
| Diviseur de puissance | composant qui répartit un signal vers plusieurs voies |
| Transducteur ultrasonore | composant émettant ou recevant des ondes acoustiques à haute fréquence |
| Positionneur | mécanisme qui oriente le réseau ou la sonde pour la mesure |

## Calibration et mathématiques

| Terme | Définition courte |
| --- | --- |
| Calibration | mesure des défauts du système, pour pouvoir les compenser |
| Problème inverse | retrouver les causes à partir des effets observés |
| Moindres carrés | méthode minimisant la somme des carrés des écarts |
| Régularisation | ajout d'une contrainte pour stabiliser une inversion |
| Conditionnement | mesure de la sensibilité d'une inversion aux erreurs de mesure |
| Pseudo-inverse | généralisation de l'inverse aux matrices non carrées |
| Récupération de phase | retrouver une phase à partir de mesures d'intensité seules |
| Méthode par rotation de phase | calibration utilisant uniquement des mesures de puissance |
| Optimisation bayésienne | méthode d'optimisation adaptée aux évaluations coûteuses |
| Processus gaussien | modèle probabiliste utilisé pour prédire une fonction inconnue |
| Stratégie d'évolution | méthode d'optimisation par population, sans gradient |
