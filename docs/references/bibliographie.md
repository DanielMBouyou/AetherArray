# Bibliographie

- Statut : à construire
- Dernière revue : 2026-08-21

Ce fichier centralise les références complètes. `research/etat-de-l-art.md`
contient les pistes et leur intérêt, ici on met la référence exacte une fois
vérifiée.

## Règles

1. Une référence n'entre ici qu'après avoir été retrouvée et vérifiée (auteurs,
   titre, lieu, année). Tant qu'elle n'est pas vérifiée, elle reste une piste
   dans l'état de l'art.
2. Chaque entrée porte un identifiant stable (`A1`, `O2`, etc.) réutilisé dans
   tout le dépôt.
3. Pour les documents en ligne, noter la date de consultation et, si possible, un
   moyen de retrouver la version consultée.
4. Ne jamais copier un document sous licence restrictive dans le dépôt. On note
   la référence, pas le fichier.

## Format

```
[ID] Auteurs. Titre. Support, année. Lien ou identifiant.
     Consulté le AAAA-MM-JJ. Fiche : research/fiches/NNN-nom.md
     Une ligne sur ce que la référence apporte au projet.
```

## Entrées vérifiées

Aucune pour l'instant. Cette section se remplit au fur et à mesure des lectures.

## Sources de recherche à utiliser

| Source | Usage | Remarque |
| --- | --- | --- |
| Bases d'articles en accès libre | trouver les versions accessibles des articles | vérifier qu'il s'agit bien de la version finale |
| Bibliothèques numériques des sociétés savantes | référence exacte et version publiée | accès parfois payant |
| Sites de conférences d'électronique numérique et de circuits reconfigurables | actes complets | souvent le meilleur point d'entrée |
| Documentation constructeur | données techniques exactes | attention aux versions obsolètes |
| Dépôts de code publics | implémentations réelles | vérifier la licence avant tout emprunt |
