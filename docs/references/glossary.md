# Glossary

- Status: living document, extended as reading progresses

## Antenna arrays

| Term | Short definition |
| --- | --- |
| Phased array | set of antennas whose phases are adjusted to steer the beam |
| Array factor | function describing the field resulting from combining the elements |
| Radiation pattern | representation of radiated power against direction |
| Main lobe | the direction in which the array radiates most |
| Side lobe | a spurious direction where the array still radiates energy |
| Grating lobe | a second lobe as strong as the main one, caused by too large a spacing |
| Beam width | angular width of the main lobe, measured at half power |
| Steering | pointing the beam away from the array axis |
| Beam squint | the pointing direction changing with frequency |
| Mutual coupling | neighbouring elements influencing each other |
| Embedded element pattern | the pattern of one element measured with the others present |
| Active impedance | the impedance seen by an element when the others are driven |
| Analogue beamforming | steering achieved by phase shifting the RF signal |
| Digital beamforming | steering achieved by computation on sampled channels |
| Far field | the region where the wave can be treated as planar |
| Near field | the region close to the array, where measurement needs special treatment |

## Components

| Term | Short definition |
| --- | --- |
| Phase shifter | component that delays the phase of a signal, adjustably |
| Attenuator | component that reduces amplitude, fixed or adjustable |
| Power divider | component splitting one signal across several channels |
| Ultrasonic transducer | device emitting or receiving high frequency acoustic waves |
| Positioner | mechanism that rotates the array or the probe for measurement |
| RF power detector | component converting RF power into a readable voltage |

## Calibration and mathematics

| Term | Short definition |
| --- | --- |
| Calibration | measuring the system defects so they can be compensated |
| Inverse problem | recovering causes from observed effects |
| Least squares | method minimising the sum of squared deviations |
| Regularisation | adding a constraint to stabilise an inversion |
| Conditioning | measure of how sensitive an inversion is to measurement error |
| Pseudo inverse | generalisation of the inverse to non square matrices |
| Phase retrieval | recovering a phase from intensity measurements alone |
| Phase rotation method | calibration using only power measurements |
| Bayesian optimisation | optimisation method suited to expensive evaluations |
| Gaussian process | probabilistic model used to predict an unknown function |
| Evolution strategy | population based optimisation method, without gradients |
